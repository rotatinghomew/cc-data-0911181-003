# 数据与业务契约

labels 的 complete_axes 指本次人工已完整检查的分类轴，其他轴没出现的标签不是负例。不同 reviewer 可以不一致，统计单位为人工决定而非咨询者。person 是稳定咨询者标识，taxonomy 每个 version 独立。

## 数据集合

- `messages`：主键为 `message`；必填字段 `message, person, month, text`，当前 72 条。
- `labels`：主键为 `message + reviewer`；必填字段 `message, reviewer, labels, complete_axes, version`，当前 96 条。
- `taxonomy`：主键为 `version + label`；必填字段 `label, axis, version`，当前 25 条。
- `hints`：主键为 `rule`；必填字段 `rule, word, label`，当前 3 条。
- `releases`：主键为 `release`；必填字段 `release, version, automatic`，当前 1 条。

集合中的主键不得重复；schema 的 foreign 引用须指向已存在的记录。可空字段保留 null 的业务含义，不自动补零。

## 查询与材料

GET 查询使用 UTF-8 JSON，错误参数返回 400，不存在的接口返回 404。重复的单值参数视为无效。summary 与 HTTP 调用同一组只读计算，材料包含数据内容指纹和生成时间，便于核对输入。当前输出描述已有数据，不承诺未实现的推断结论。

## 现有办理协作

人工选择的主题经 routing.assign 分别转办，教研组确认兴趣后计入开班人数，全部转办办结后汇合回复。当前只接人工主题，不自动采用模型判断。

每个操作在本地业务日志的事务中更新；失败不提交半条办理记录。已有人工流程可以继续使用，新增分析尚未作为这些操作的有效依据。接口传入业务标识，未知标识或不满足条件返回错误，不自动补建对象。
